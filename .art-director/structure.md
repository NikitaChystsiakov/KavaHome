# Структура сайта KavaHome (2026-11-13)

Источник: ответы Эллы 2026-11-13, ТЗ, Zara Home (карточка товара, корзина), Tekla/Parachute (о бренде, B2B). Эскизы блока партнёров: `sketch/partners.html`.

## Страницы
| Адрес | Страница | Что на ней |
|---|---|---|
| `/` | Главная (утверждена) | + полоса «Нам доверяют» перед «Для отелей» |
| `/catalog` | Каталог | тот же каталог, что на главной, с H1 и SEO; фильтры в URL |
| `/catalog/[модель]?cvet=` | Карточка товара | слева фото столбиком (телефон: листание), справа липкий блок: название, цена выбранного размера, цвета квадратами, размеры кнопками с подписью назначения, «В корзину», состав/плотность/уход/доставка раскрывашками; ниже «другие цвета» и «эта коллекция» |
| `/korzina` | Корзина + заявка | список, количество, итого; форма на той же странице: имя, телефон, доставка (самовывоз Волковичи / по Беларуси + адрес), комментарий. «Отправить заказ» → WooCommerce + Telegram → `/spasibo` |
| `/o-nas` | О бренде | 3+ года, магазины и маркетплейсы (4,9), почему выбирают (хлопок, 420–500 г/м², пошив, палитра), кто покупает (для себя, в подарок, отели), партнёры |
| `/dostavka` | Доставка и оплата | по всей Беларуси, самовывоз/шоурум с картой, оплата и стоимость — менеджер при подтверждении |
| `/biznes` | Для бизнеса | отели/санатории/фитнес (бирки партнёров), опт индивидуально, логотип вышивкой/жаккардом, сертификаты, форма |
| `/kontakty` | Контакты | телефон, почта, часы, шоурум-склад + карта, реквизиты |
| `/faq` | Вопросы и ответы | уход, размеры, плотность, заказ, доставка, опт (черновик на согласование Элле) |
| `/privacy` | Политика персональных данных | обязательна для форм |
| `/spasibo`, 404 | есть | |

## Меню и подвал
Шапка: Каталог · Для бизнеса · (поиск) · Корзина со счётчиком. Бургер: коллекции, каталог, назначения, бизнесу, покупателям (доставка, о бренде, вопросы, контакты). Подвал: Покупателям / Бизнесу / Контакты + адрес шоурума.
